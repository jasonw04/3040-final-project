1. install the following kagglehub numpy pandas matplotlib scikit-learn seaborn scipy tabulate

you can use requirements.txt 
pip install -r requirements.txt

2. to run the data preprocessing, data cleaning, train and test run data_preprocessing and evaluate_and_report
when running data_preprocessing let it give it around 5 minutes to train and test all of the models

3. to run summary stats run summary_stats

4. to run the app run the following in the terminal 
python -m streamlit run app.py

make sure that all of the pngs are outside of the 3040 final project folder to run the steamlit app
